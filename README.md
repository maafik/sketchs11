# Любимец

Сайт портретов с питомцем: стиль, заявка, бесплатное превью, печать или файл.

## Заявки на почту

Ключ Web3Forms уже прописан в `js/config.js`.

Бесплатный тариф **не принимает файлы** (`file uploads` — Pro). Поэтому сайт сжимает фото в браузере и отправляет их обычными полями письма, не как вложения. В письме они будут в полях `photo_1`, `photo_2`, `photo_3` как картинки в формате data URL.

Если нужны оригиналы без сжатия — в Web3Forms включите Pro.
